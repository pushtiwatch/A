# Testimony transcripts

Public, timestamped transcripts and English summaries of Gujarati and Hindi testimony videos posted on YouTube. The files record what speakers allege. The allegations are not independently verified. Named individuals are presumed innocent unless proven in court.

- [Inventory](inventory.json) — an index of every video in this repository
- [Taxonomy](taxonomy.json) — tags and flags used in the files
- [Pipeline guide](GUIDE.md) — how the files are produced
